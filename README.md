# CSRT

## 项目简介

CSRT（CCW Security Research Toolkit）是一个面向 CCW 平台的安全研究与作品分析工具。项目最初以「CCW 安全研究工具」为名发布，后更名为 SRT，最终定名为 CSRT，逐步从简单的代码执行器演进为集作品分析、扩展审查、数据管理、UI 增强于一体的综合性研究工具集。

当前版本：**v2.9.7**

---

## 功能概览

### 作品分析

- **作品信息获取**：读取当前作品的 URL、创作者、VM 实例、扩展列表等基础信息
- **扩展检测**：综合 `wildExtensions` / `extensionURLs` / `loadedExtensions` / `targets.scan` 多来源判定自定义扩展与官方扩展
- **扩展代码查看与修改**：在线拉取自定义扩展代码，支持修改后重新加载
- **恶意代码检测**：内置多种可疑模式识别，辅助审查扩展安全性
- **作品下载**：一键导出当前作品为 `.sb3`，支持资源并发下载
- **作品捕获**：自动捕获 `loadProject` 加载的作品，保留最近 20 个，支持单个或批量下载

### 扩展管理

- **扩展拦截窗口**：加载作品前审查扩展，可允许 / 拒绝
- **扩展注入检测**：通过 `CSRTExtensionInjector` 监听扩展加载事件
- **Eureka 内嵌版**：支持 URL 加载、代码粘贴、文件上传三种方式加载扩展
- **允许未知扩展**：基于 `cj-allow-unknown-extensions`，后台静默激活

### 数据与变量

- **变量管理**：精灵 / 克隆体选择、搜索过滤、折叠展开
- **变量锁定**：通过 `Object.defineProperty` 劫持 setter，锁定后拒绝修改
- **云数据管理**：CCWData 作品 / 用户云变量读写
- **经济合约面板**：查看合约列表、余额、规则，支持执行规则与无偿注资
- **成就与排行榜**：查看成就 / 排行榜列表，支持一键获得成就、修改分数
- **本地用户信息**：读取 / 导入 / 导出 / 清除当前登录用户信息

### 身份与伪装

- **切换身份**：替代原「伪装身份」，同时劫持 `students/self/detail` 与 `study-community/member/detail`
- **伪装手机号**：伪装认证等级 / 手机号 / 信誉 / QQ
- **主页查看器**：展示封禁用户主页信息，支持注销用户伪装

### 作品替换与回溯

- **作品替换器**：上传本地 `.sb3`，访问任意作品时自动替换
- **版本回溯**：上传替换文件后可在拦截窗口选择加载历史版本
- **动态替换**：无需刷新页面即可切换当前作品
- **角色插入器**：向当前作品插入本地 `.sprite3` 角色文件

### 开发与调试

- **代码执行面板**：`eval` 执行任意 JS（安全研究用）
- **元素检查器**：可视化查看页面元素信息、HTML 结构、CSS 样式，支持复制选择器与删除元素
- **性能监控**：实时显示延迟 / FPS / 请求数，面板可拖动
- **私有日志系统**：`privateLog` 支持日志级别过滤、上限控制、`onChange` 监听
- **日志过滤工厂**：`CSRTConsoleFilter` 支持关键词 / 正则 / 白名单配置
- **统一 XHR 拦截器**：`XHRInterceptor` 单一入口管理所有网络请求
- **统一配置管理**：`CSRTConfig` 集中管理 API 端点 / 页面特征 / 存储键 / 超时时间

### UI 与交互

- **毛玻璃主题**：`injectGlassTheme()` 注入完整玻璃拟态样式
- **悬浮球**：SVG LOGO + 径向光晕 + 毛玻璃质感，支持平滑跟随与触摸
- **工具窗口**：支持拖动、Tab 切换、缩放控制（80%~150%）
- **动态 Tab 注入**：检测到扩展时自动添加对应面板 Tab
- **Toast 通知**：毛玻璃样式 + 淡入淡出动画

## 核心模块

- `CSRTConfig`：统一配置管理，API 端点 / 页面特征 / 存储键 / 超时时间集中管理
- `CSRTConsoleFilter`：日志过滤工厂，支持关键词 / 正则 / 白名单
- `privateLog`：私有日志系统，支持上限控制、统计、监听
- `CSRTDatabase`：可 watch 的数据存储，支持 delete / clear / unwatch / transform / size / forEach
- `XHRInterceptor`：统一 XHR 拦截器，支持注册 / 注销与三种返回值语义
- `BlobURLRegistry`：Blob URL 兼容层，自动清理过期 URL
- `PageFeatureGate`：页面功能门控，按页面类型动态加载功能
- `ReplacerStorage`：作品替换器统一存储管理
- `EurekaEmbedded`：Eureka 内嵌版，支持多种加载方式
- `CSRTExtensionInjector`：扩展注入检测

## 使用说明

CSRT 以油猴脚本形式运行，安装后通过悬浮球或快捷键打开工具窗口。主要操作入口包括：

- **悬浮球**：单击打开 / 关闭工具窗口，可拖动
- **油猴菜单**：伪装身份、作品替换器、角色插入器等快捷操作
- **工具窗口 Tab**：作品信息、数据修改、代码执行、审查日志、元素检查器等

> 本项目仅供安全研究与学习交流使用，请勿用于任何违反平台规定或法律法规的用途。
