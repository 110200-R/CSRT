# CSRT pro - CCW Security Research Tool

## 项目简介

CSRT（CCW Security Research Tool）是一个面向 CCW 平台的深度安全研究与作品分析油猴脚本
由开发者 `110200` 主导维护，并在其 [官方网站](https://csrt.netlify.app/) 持续更新
项目从早期的简单代码执行器，逐步演进为一个涵盖了**底层环境反检测、网络请求拦截重写、扩展发布与审查、虚拟机(VM)数据操控、以及 UI 生态增强**的重型油猴脚本体系
它不仅是安全研究人员的利器，也是 CCW 创作者突破平台功能限制、进行深度二次开发的生态基座
目前版本已迭代至 **v2.9.8+**，在对抗平台反作弊机制和绕过扩展审核限制方面积累了极其深厚的技术沉淀

---

## 核心功能概览

### 反检测与隐身 (v2.9.8+ 核心亮点)
- **`CSRT_AntiDetection` 统一反检测引擎**：彻底重构，将环境洗白、DOM 隐身、劫持伪装融为一体
- **劫持行为洗白**：完美掩盖 `XHR`、`fetch`、`console`、`bind` 等原生方法的篡改痕迹，防范第三方反作弊扩展（如 YinSecurity）的检测
- **底层 VM 洗白**：通过持续覆盖，确保 `loadProject`、`setCCWAPI` 等核心方法在查看时永远是 `[native code]`
- **DOM 物理级隐身**：拦截 `querySelector` 对 `.csrt-*` 的查询，防止工具特征暴露
- **属性混淆**：动态随机化宿主节点的 `data-*` 属性，并过滤 `MutationObserver` 的监控，防止被外部脚本嗅探

### 扩展发布与绕过机制 (最新攻关)
- **免审发布流程（API 自动化）**：
  - 自动打包带有标准结构 `project.json` 的扩展工程
  - 自动生成包含积木坐标、参数、`wildExtensions` 的绝对合法 JSON
  - 将 `.sb3` 自动传至 OSS 并调用 `creation/update` 接口更新作品状态
- **纯手工极简 ZIP 生成器**：在无 JSZip 或 CDN 被墙的情况下，直接通过 `Uint8Array` 与 `DataView` 写出完全合规的 ZIP 二进制，解决环境依赖问题。
- **Data URI 内联注入 / 内存挂载**：针对 Gandi 反盗作机制，提供 Base64 内联与本地 VM 内存直接挂载（`Scratch.extensions.register`）双保险方案。

### 扩展拦截与审查 (Extension Interceptor)
- **加载前拦截**：在作品加载 `loadProject` 的瞬间，解包解析项目，拦截所有未审查的自定义扩展。
- **在线热修改**：支持查看扩展 JS 源码，并在修改后通过 Blob URL 原地热加载，支持版本回退，无需刷新页面。
- **Eureka 内嵌核心**：全方位支持 URL 拉取、代码粘贴、本地文件上传加载第三方扩展，打破平台限制。
- **允许未知扩展**：后台静默拦截扩展中心的校验请求，强行放行未上架的扩展。


### 虚拟机 (VM) 与数据修改 (VM & Data)
- **变量透视与锁定**：支持角色/克隆体切换 利用 `Object.defineProperty` 劫持变量的 setter/getter，实现变量锁定，拒绝作品内部脚本篡改（防外挂机制）。
- **云数据管理 (CCWData)**：直观读写 CCWData 作品的云端变量与用户级云端变量。
- **经济合约操控**：可视化遍历作品内的智能合约，支持“一键全取”奖励，并拦截作品恶意的自动投币请求。
- **排行榜与成就**：直接向服务器提交伪造的排行榜分数，一键解锁全成就。

### 身份伪装与数据劫持 (Identity & Data)
- **深度身份切换**：不仅劫持 `students/self/detail`，还覆盖 `study-community/member/detail`，同步伪造用户信息，并自动写入 `cookie-user-id` 防掉登录。
- **主页查看器**：深度解析并伪装“已注销用户”与“被封禁用户”的主页及作品列表，展示封禁倒计时。
- **伪装环境信息**：伪造手机号、身份认证等级（L2）、信誉分与 QQ 绑定状态。

### UI 与交互体系
- **毛玻璃视效 (Glassmorphism)**：全窗口、悬浮球及控制台均采用高质感的半透明模糊背景与光晕特效。
- **全局平滑悬浮球**：支持灵动拖拽 触摸事件 RGB 光晕 防检测属性 并在边缘自动吸附
- **可调色工具面板**：支持 Tab 切换、窗口拖拽、以及 `80% - 150%` 的全局缩放控制 窗口位置本地记忆。
- **元素检查器**：类似 Chrome DevTools 的页面元素审查工具，支持悬停高亮、查看 CSS/HTML 结构、物理删除节点。
- **性能监控 (Performance Monitor)**：基于 Canvas 绘制的实时曲线图，监控页面 FPS、网络延迟与请求数。
- **审查日志系统**：提供 `privateLog` 支持日志分级、长度控制；`CSRTConsoleFilter` 支持正则过滤控制台污染。

### 开发者工具
- **作品替换器**：支持本地 `.sb3` 替换线上作品，含 XHR 拦截与 LoadProject 拦截双模式，支持版本回溯。
- **统一 XHR 拦截器 (`XHRInterceptor`)**：单一入口管理所有网络请求，采用索引化匹配，极大提升性能。
- **私有日志系统 (`privateLog`)**：支持日志分级、上限控制（如 1000 条）、监听器模式。
- **日志过滤工厂 (`CSRTConsoleFilter`)**：支持正则、关键词及白名单，防止控制台被 CSRT 自身日志刷屏。
- **统一配置 (`CSRTConfig`)**：集中管理 API、页面正则、存储键与超时时间。
- **一键导出作品**：支持导出全作品 `.sb3`、单个角色 `.sprite3` 及全部角色 ZIP 打包。
- **角色插入器**：直接向运行中的 VM 插入 `.sprite3`。

### 免审发布与扩展注入 (Extension Publishing & Injection)
*针对 CCW 严格的审核机制与反盗作机制，提供多套降维打击方案。*
- **标准 `.sb3` 结构生成**：在内存中动态构建符合官方规范的 `project.json`，自动挂载 `wildExtensions`、`gandi.assets` 及积木（blocks）实体。
- **纯手工 ZIP 打包 (`manualZip`)**：不依赖任何第三方 CDN 库，直接通过 `Uint8Array` 和 `DataView` 拼装符合 ZIP 规范的二进制流，彻底解决 `JSZip` 加载失败问题。
- **API 自动化发布**：直接调用 `creation/update` 等官方后端接口，自动上传 OSS 并发布扩展工程。
- **Data URI 内联注入**：将 JS 代码转为 Base64 直接塞入工程，绕过 Gandi 的扩展 URL 白名单拦截。
- **VM 内存挂载 (God Mode)**：绕开所有网络和 UI 校验，直接向 `Scratch.extensions.register` 底层注入扩展，实现“无中生有”的本地积木渲染。

## 关键模块解析

- **`CSRT_AntiDetection`**：统一反检测引擎，包含 `patchFunctionToString` (洗白)、`sanitizeVM` (底层覆盖)、`setupYinSecurityInterceptor` (DOM 物理隐身) 等。
- **`publishExtension`**：强力的扩展发布组件，包含沙箱解析、标准 JSON 构建、纯手工极简 ZIP 打包、API 自动发布与内联绕过。
- **`CSRTConsoleFilter`**：日志过滤工厂，在劫持 `console` 的同时伪装 `toString`，防范检测。
- **`XHRInterceptor`**：基于前缀树/哈希表索引的网络请求拦截器，性能极高。
- **`CSRTDatabase`**：可 `watch` 的响应式数据存储。
- **`PageFeatureGate`**：页面门控，非作品页不加载 VM 等重型功能以节省性能。
- **`EurekaEmbedded`**：内嵌的第三方扩展热加载器。

## 使用说明

CSRT 以油猴脚本形式运行，安装后通过悬浮球或快捷键 `Ctrl+Shift+E` 打开工具窗口。主要操作入口：

- **悬浮球**：单击打开/关闭窗口，可任意拖动。
- **油猴菜单**：提供作品替换器、身份切换、加载本地脚本等快捷入口。
- **控制台 API**：暴露 `__CSRT` 全局变量供高级调试，如 `__CSRT.consoleFilter.enable()`。

> ⚠️ **免责声明**：本项目仅供安全研究与学习交流使用，请勿用于任何违反平台规定或法律法规的用途。
