# CSRT pro - CCW Security Research Tool

## 项目简介

CSRT（CCW Security Research Tool）是一个面向 CCW 平台的深度安全研究与作品分析油猴脚本。项目从早期的简单代码执行器，逐步演进为一个集底层环境隐身、扩展拦截与发布、内存数据管理、UI 增强于一体的重型工具集。目前版本已迭代至 **v2.9.8+**，在对抗平台反作弊机制和绕过扩展审核限制方面积累了极其深厚的技术沉淀。

---

## 核心功能概览

### 反检测与隐身 (v2.9.8+ 核心亮点)
- **`CSRT_AntiDetection` 统一反检测引擎**：彻底重构，将环境洗白、DOM 隐身、劫持伪装融为一体。
- **劫持行为洗白**：完美掩盖 `XHR`、`fetch`、`console`、`bind` 等原生方法的篡改痕迹，防范第三方反作弊扩展（如 YinSecurity）的检测。
- **底层 VM 洗白**：通过持续覆盖，确保 `loadProject`、`setCCWAPI` 等核心方法在查看时永远是 `[native code]`。
- **DOM 物理级隐身**：拦截 `querySelector` 对 `.csrt-*` 的查询，防止工具特征暴露。
- **属性混淆**：动态随机化宿主节点的 `data-*` 属性，并过滤 `MutationObserver` 的监控，防止被外部脚本嗅探。

### 扩展发布与绕过机制 (最新攻关)
- **免审发布流程（API 自动化）**：
  - 自动打包带有标准结构 `project.json` 的扩展工程。
  - 自动生成包含积木坐标、参数、`wildExtensions` 的绝对合法 JSON。
  - 将 `.sb3` 自动传至 OSS 并调用 `creation/update` 接口更新作品状态。
- **纯手工极简 ZIP 生成器**：在无 JSZip 或 CDN 被墙的情况下，直接通过 `Uint8Array` 与 `DataView` 写出完全合规的 ZIP 二进制，解决环境依赖问题。
- **Data URI 内联注入 / 内存挂载**：针对 Gandi 反盗作机制，提供 Base64 内联与本地 VM 内存直接挂载（`Scratch.extensions.register`）双保险方案。

### 扩展拦截与审查
- **扩展拦截窗口**：在作品加载前深度解析 `.sb3` 内的 `project.json`，拦截可疑扩展并要求用户审查。
- **在线代码查看与修改**：支持在线拉取扩展 JS，修改后通过 Blob URL 重新热加载，并可回退。
- **Eureka 内嵌版**：支持通过 URL、粘贴代码、上传 `.js` 文件三种方式动态加载扩展。
- **允许未知扩展**：后台静默拦截扩展中心的校验请求，强行放行未上架的扩展。

### 数据修改与经济系统
- **变量管理与锁定**：支持精灵/克隆体切换，搜索过滤；利用 `Object.defineProperty` 劫持 setter，实现变量锁定与防篡改。
- **云数据管理**：读写 CCWData 的作品/用户云变量。
- **经济合约面板**：支持一键遍历合约 award 规则进行“一键全取”，拦截作品恶意自动投币请求。
- **成就与排行榜**：支持一键获得成就，直接修改排行榜分数。

### 身份伪装与主页查看
- **身份切换**：劫持 `students/self/detail` 等接口伪造响应，同时写入 `cookie-user-id` 防止掉登录。
- **主页查看器**：伪装箱封禁用户、注销用户的个人主页及作品列表，支持查看封禁剩余时间。
- **伪装手机号**：伪造认证等级、手机号及 QQ 信息。

### UI 与交互体系
- **毛玻璃主题 (Glassmorphism)**：全窗口、按钮、输入框均采用高质感的玻璃拟态设计。
- **悬浮球**：支持丝滑拖拽、RGB 光晕、防检测属性。
- **工具窗口**：支持 Tab 拖拽换位、窗口缩放（80%~150%）、窗口位置本地记忆。
- **性能监控面板**：基于 Canvas 绘制的实时曲线图，监控 FPS、延迟与请求数。
- **元素检查器**：强力的 DOM 检查工具，支持悬停高亮、查看 CSS/HTML、一键复制选择器及物理删除元素。

### 开发者工具
- **作品替换器**：支持本地 `.sb3` 替换线上作品，含 XHR 拦截与 LoadProject 拦截双模式，支持版本回溯。
- **统一 XHR 拦截器 (`XHRInterceptor`)**：单一入口管理所有网络请求，采用索引化匹配，极大提升性能。
- **私有日志系统 (`privateLog`)**：支持日志分级、上限控制（如 1000 条）、监听器模式。
- **日志过滤工厂 (`CSRTConsoleFilter`)**：支持正则、关键词及白名单，防止控制台被 CSRT 自身日志刷屏。
- **统一配置 (`CSRTConfig`)**：集中管理 API、页面正则、存储键与超时时间。
- **一键导出作品**：支持导出全作品 `.sb3`、单个角色 `.sprite3` 及全部角色 ZIP 打包。
- **角色插入器**：直接向运行中的 VM 插入 `.sprite3`。

## 关键模块解析

- **`CSRT_AntiDetection`**：统一反检测引擎，包含 `patchFunctionToString` (洗白)、`sanitizeVM` (底层覆盖)、`setupYinSecurityInterceptor` (DOM 物理隐身) 等。
- **`publishExtension`**：强力的扩展发布组件，包含沙箱解析、标准 JSON 构建、纯手工极简 ZIP 打包、API 自动发布与内联绕过。
- **`CSRTConsoleFilter`**：日志过滤工厂，在劫持 `console` 的同时伪装 `toString`，防范检测。
- **`XHRInterceptor`**：基于前缀树/哈希表索引的网络请求拦截器，性能极高。
- **`CSRTDatabase`**：可 `watch` 的响应式数据存储。
- **`PageFeatureGate`**：页面门控，非作品页不加载 VM 等重型功能以节省性能。
- **`EurekaEmbedded`**：内嵌的第三方扩展热加载器。

## 使用说明

CSRT 以油猴脚本形式运行，安装后通过悬浮球或快捷键 `Ctrl+Shift+E` 打开工具窗口。主要操作入口：

- **悬浮球**：单击打开/关闭窗口，可任意拖动。
- **油猴菜单**：提供作品替换器、身份切换、加载本地脚本等快捷入口。
- **控制台 API**：暴露 `__CSRT` 全局变量供高级调试，如 `__CSRT.consoleFilter.enable()`。
